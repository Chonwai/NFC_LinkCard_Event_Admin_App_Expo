現場工作手冊

活動主辦人與現場閘口工作人員

這本手冊給誰看

  • 主辦人：活動的擁有者，可看名單、設定與所有現場工具。
  • 閘口工作人員：只被授權在現場報到與操作 NFC，讀不到完整名單。

怎麼用這本手冊

  • 每一節都是一件事。跟著號碼做，做完就完成一件事。
  • 圖上的圓形數字，對應圖下方的說明表。
  • 如果畫面和你看到的不一樣，先看那一步的說明；差異通常是有原因的。
  • 看到「尚未開放」的功能，就代表人為暫時不能做，需要人工處理。

這些畫面怎麼來的

畫面以手機尺寸的瀏覽器視窗擷取（390 × 844，2 倍解析度）。相機與 NFC 屬於手機硬體，瀏覽器沒有，因此這兩個功能的相關畫面會顯示 App 自己的提示文字。

第一部分：開始使用

A1 登入 App

誰做主辦人
什麼時候第一次拿到手機，或換了裝置之後。
要達到什麼用自己的帳號登入，看到自己負責的活動。
開始之前已收到主辦方提供的帳號電郵與密碼。
做完之後停在「我的活動」畫面，可以開始選活動。

A1-1 打開 App。

你會看到什麼：出現登入畫面：上方是 App 名稱，中間要你填電郵與密碼。

1電郵欄位
2密碼欄位

A1-2 點一下電郵欄位，輸入你的電郵地址。

你會看到什麼：欄位出現你輸入的文字。

1已輸入的電郵

A1-3 點密碼欄位輸入密碼，然後按「登入」。

你會看到什麼：密碼會顯示成圓點。右邊的眼睛圖示可以切換顯示，確認自己有沒有打錯。

1密碼欄位（顯示為圓點）
2按這裡登入

A1-4 按「登入」。

你會看到什麼：登入成功後直接進入「我的活動」，畫面上列出你負責的活動。

1已經登入，這是你的活動列表

A2 選擇要處理的活動

誰做主辦人
什麼時候每次打開 App 之後。
要達到什麼進入正確活動的現場工具。
開始之前已經登入。
做完之後停在該活動的「活動概覽」。

A2-1 在「我的活動」找你要辦的活動。

你會看到什麼：每張活動卡顯示活動名稱、狀態、你的身分、報名人數與參展商數目。

1活動名稱
2活動狀態

A2-2 看一下卡片上的數字，確認是同一場活動。

你會看到什麼：報名人數與參展商數目就在名稱下方，不用點進去。

1報名人數與參展商數目

A2-3 點一下活動卡。

你會看到什麼：進入「活動概覽」，最上方是這場活動的即時數字。

1已進入這場活動的概覽

A3 檢查手機狀態與登出

誰做主辦人
什麼時候開場前確認裝置沒問題，或交還手機給別人之前。
要達到什麼確認 App 版本與 NFC 是否可用，需要時安全登出。
開始之前已經登入。
做完之後知道這支手機能不能寫卡；登出後回到登入畫面。

A3-1 點畫面最下方的「設定」。

你會看到什麼：看到「帳號」與「裝置」兩段資料。

1你現在在設定頁
2帳號區

A3-2 看「NFC 狀態」那一行。

你會看到什麼：顯示「支援」代表這支手機可以寫卡與讀卡；顯示「不支援」就要換另一支手機做 NFC 工作。

1NFC 狀態決定這支手機能不能寫卡
2回報問題時要說出這個版本號

A3-3 要交還手機時，捲到最下面按「登出」。

你會看到什麼：回到登入畫面，別人就看不到你的活動資料。

1交還手機前按這裡

第二部分：開場之前

B1 掌握活動現況

誰做主辦人
什麼時候開場前，以及現場期間每隔一段時間。
要達到什麼一眼看出報名人數、已報到人數與到場率。
開始之前已經進入這場活動。
做完之後知道現場節奏，並可直接跳到常用工具。

B1-1 打開這場活動的「活動概覽」。

你會看到什麼：四格數字：報名人數、已報到、參展商、到場率。

1報名人數
2已報到
3到場率

B1-2 如果某格顯示「—」而不是數字，看它下面那行說明。

你會看到什麼：破折號代表「這個數字沒拿到」，不是「零」。畫面上會寫明原因。

1破折號的解釋

B1-3 往下看「快速操作」，這裡是現場最常用的入口。

你會看到什麼：七個按鈕：掃碼簽到、Token、名單、NFC 寫卡、讀取 tagUid、交換名片、Badge。

1掃碼簽到：最常用
2名單：查人用
3NFC 寫卡：發手環用

B2 點清 Badge 庫存

誰做主辦人
什麼時候開場之前，和發到手環用完的時候。
要達到什麼知道還有幾張空白卡、已經發出去幾張。
開始之前已經進入這場活動。
做完之後心裡有數，知道要不要再拆一批新卡。

B2-1 從「快速操作」按「Badge」。

你會看到什麼：上方是查詢框，下方是這場活動所有的 Badge。

1知道卡片編號時用這裡查
2全部卡片清單

B2-2 看每張卡的狀態標籤。

你會看到什麼：「未綁定」是還沒發出去的空白卡；「啟用」是已經發給人、正在使用。

1已發給人、正在使用

B2-3 看每張卡的批次名稱。

你會看到什麼：批次名稱告訴你這張卡是從哪一疊拿出來的，方便對帳。

1批次名稱

B3 先認識名單

誰做主辦人
什麼時候開場之前，先了解會來哪些人。
要達到什麼看得懂名單上每一列在講什麼。
開始之前已經進入這場活動，而且你的帳號讀得到名單。
做完之後知道怎麼看一列報名，也知道怎麼複製報名編號。

B3-1 從「快速操作」按「名單」。

你會看到什麼：看到這場活動的報名清單。

1報名清單

B3-2 讀一列報名。

你會看到什麼：由左至右是姓名、電郵（中間會打星號保護）、狀態標籤、報名編號、公司、報名時間。

1這一列就是一位報名者
2狀態：已確認＝可以進場

B3-3 點一下報名編號。

你會看到什麼：編號會被複製起來，方便你貼到別的系統或傳給同事。

1點這裡複製編號

第三部分：現場報到

C1 用相機掃碼報到

誰做閘口工作人員
什麼時候參加者遞上手機或紙本上的 QR code 時。這是最快的方法。
要達到什麼把 QR code 換成一次報到紀錄。
開始之前已在活動的掃碼簽到畫面，並且相機可用。
做完之後畫面顯示報到結果，約 15 秒後自動回到掃碼狀態，應付下一個人。

C1-1 從「快速操作」按「掃碼簽到」。

你會看到什麼：看到上方「總簽到」，下方是掃描框。

1累計已報到人次
2把 QR code 對準這個框

C1-2 確認現在是「掃描模式」。

你會看到什麼：上方兩個標籤可以切換：掃描模式用相機，手動輸入用鍵盤。

1現在是用相機
2相機不行時改按這裡

C1-3 把手機對準 QR code。如果畫面顯示相機不能用，看它給你的兩條路。

你會看到什麼：「允許使用相機」是再要一次權限；「改用輸入模式」是立刻轉成手動輸入。兩者都不會讓參加者白排。

1先試著重新開啟相機
2相機真的不行就按這裡

關於這張圖：這張截圖在瀏覽器上擷取。瀏覽器沒有 NFC，所以畫面出現 App 自己的提示；手機上不會有這行提示，其餘畫面相同。真正感應卡片的那一下無法在瀏覽器示範。

C2 相機不能用時，改用手動輸入

誰做閘口工作人員
什麼時候QR code 破了、手機反光、或相機被其他程式佔用時。
要達到什麼一樣完成報到，不用叫參加者重排。
開始之前已在活動的掃碼簽到畫面。
做完之後跟掃碼一樣得到報到結果。

C2-1 相機不能用時，先試「允許使用相機」。

你會看到什麼：多數情況按一次就會好，不用離開這個畫面。

1先試這個

C2-2 還是不行，按「改用輸入模式」。

你會看到什麼：掃描框變成一個輸入框，可以直接打報名編號。

1在這裡打報名編號

C2-3 把參加者提供的報名編號打進去。

你會看到什麼：大小寫不拘，前後多打了空格也沒關係，系統會自己校正。

1剛打進去的編號

C2-4 按「查詢並報到」。

你會看到什麼：畫面會顯示「確認中…」，然後出現結果卡。

1送出後要看的就是這個

C2-5 看結果卡。

你會看到什麼：綠色「報到成功」，卡片上有姓名、票種與報到時間，可以放行。

1成功，可以放行
2核對票種對不對

C3 看懂四種報到結果

誰做閘口工作人員
什麼時候每次報到之後。
要達到什麼知道哪一種可以放行、哪一種要叫主管。
開始之前已經完成至少一次查詢。
做完之後遇到任何結果都知道下一步做什麼。

C3-1 第一種：票有效，而且剛剛完成報到。

你會看到什麼：綠色標題「報到成功」。直接放行。

1放行

C3-2 第二種：這個人剛剛已經報到過了。

你會看到什麼：標題是「重複簽到」。不要重複放行，先問他是不是已經進場了。

1不是新人，先確認

C3-3 第三種：查不到這張票。

你會看到什麼：標題是「無效報名」。先確認編號有沒有打錯，再請參加者出示原本的確認信。

1不要放行

C3-4 第四種：連線出問題。

你會看到什麼：畫面顯示「網路連線異常」。這句話跟「無效報名」完全不同：票可能是好的。改用人工核對或換個網路再試，不要當成假票。

1是網路問題，不是票的問題

C4 現場補報名

誰做閘口工作人員
什麼時候有人臨時到場，沒有事先報名。

開始之前已知道要給他哪一種票。
做完之後名單多一筆紀錄，可以直接接去簽到或寫卡。

C4-1 打開現場補報名。

你會看到什麼：看到票種與欄位。電郵是必填，名與姓分開兩格。

1先選票種
2電郵是必填

C4-2 填寫參加者的資料。

你會看到什麼：星號欄位都要填。電話與公司可以留空。

1電郵：必填

C4-3 跟參加者讀一次條款，勾選同意，然後按「建立報名」。

你會看到什麼：必須先勾同意，按鈕才會真的送出。

1送出後的結果

C4-4 看建立結果，然後接去簽到或寫卡。

你會看到什麼：提醒：需要付款的票種，報名建立了但還未付款，不能當成已入場。

1直接接去簽到
