## 📋 完成定義（DoD）— 每個 WP 必須滿足五項

1. **代碼完成**：符合 doc 13 缺口與 API Contract
2. **測試通過**：`npx tsc --noEmit` + `npm run lint` 全綠
3. **真機/瀏覽器驗證**：截圖或錄影（**tsc 過 ≠ 可用**）
4. **commit 紀錄**：hackathon 式小步（每子功能一個 commit）
5. **WP 編號**：commit message 含 WP 編號（如 `(WP-A7)`）
