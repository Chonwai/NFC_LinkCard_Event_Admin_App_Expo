## 🔴 P0 — 11 月必須上線

### 模組 A：QR 掃碼簽到（Check-in）
- 啟動相機即時掃碼
- **三態回饋**：✅ 有效（顯示姓名/公司/票種/Token）→ ⚠️ 重複（需主管覆核）→ ❌ 無效（快速補報名入口）
- 成功：**震動 + 音效 + 大字綠色畫面**（現場嘈雜環境必需）
- 頂部顯示簽到計數
- **每筆寫入時間戳 + 閘口編號 + 操作員 ID**

### 模組 B：Token / 積分管理
- **增值**：快捷金額（+10/+50/+100，後端可配置）、自訂金額、來源標記
- **扣減**：依兌換品項清單點擊（咖啡−20、零食−10、禮品−50），餘額不足置灰
- **流水表**：時間/操作員/金額/類型/備註
- **二次確認**防呆
- ⚠️ 動詞是 `deduct`（不是 `redeem`！見 04-KNOWN-PITFALLS）

### 模組 C：NFC 手帶 / 掛牌綁定
- 簽到後自動跳出「發卡」步驟
- 寫入 / 綁定 NFC UID ↔ 用戶 Account ID
- 支援：**換卡**（舊卡作廢）、**補發**、**退卡**

### 模組 D：參加者名單與現場管理
- **搜尋**（姓名/手機/Email/編號）、**篩選**（票種/簽到/公司/Token）、**排序**
- 用戶詳情頁：資料 + 報名 + 簽到 + Token 流水 + NFC + 社團
- **現場補報名**：精簡表單 → 觸發 Email（含帳密 + QR）→ 立即發卡
