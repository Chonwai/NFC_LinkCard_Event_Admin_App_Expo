## Tech Stack

- **Runtime**: Expo SDK `~57.0.13` / React Native `0.86.2` / React `19.2.3` / TypeScript `~5.9.3`
- **Router**: expo-router `~57.0.13` — file-based routing under `src/app/`, `experiments.typedRoutes: true`
- **State**: zustand `^5.0.15` — 2 stores (`auth`, `event`)
- **HTTP**: axios `^1.19.0` — `src/services/api.ts` singleton, JWT bearer interceptor (same architecture as Promoter)
- **Native modules**: `react-native-nfc-manager` (NFC credential bind), `expo-camera` (QR check-in),
  `expo-secure-store` (token), `expo-linking`, `expo-audio`, `expo-clipboard`, `expo-image-picker`
- **UI helpers**: `react-native-safe-area-context`, `react-native-screens`, `react-native-svg` +
  `react-native-qrcode-svg`, `react-native-web`
- **Styling**: RN `StyleSheet` + three-layer design tokens (`src/constants/theme.ts`) —
  **copied from the Promoter App, and since diverged** (see "Shared code with Promoter" below)
- **Lint/Format**: eslint 9 + `eslint-config-expo`, prettier + `@trivago/prettier-plugin-sort-imports`,
  husky 9 + lint-staged 15
- **Testing**: `node:test` (no Jest) — `npm test` runs `tests/*.test.mjs` **and** `tests/journeys/*.test.mjs`
- **CI**: `.github/workflows/ci.yml` — runs `regenerate:typed-routes`, `typecheck`, `lint`,
  `format:check`, `npm test`
- **Build**: EAS Build (`eas.json`: development / preview / production); all three profiles set
  `EXPO_PUBLIC_API_URL` and `EXPO_PUBLIC_WEB_URL`
- **OTA updates**: ❌ **not available today.** No `expo-updates` dependency and no `updates` block in
  `app.json`. Enabling it adds a native module ⇒ rebuild + store submission. See `D-15`.
- **Platform**: iOS `supportsTablet: true`; Android permissions = CAMERA + NFC (no `RECORD_AUDIO`).
  `ios/` **is committed** (18 tracked files) — treat native-project edits as `runtimeVersion`-bumping.

## API Endpoint Inventory

Base URL = `API_BASE_URL` (origin only, **no `/api`**; see `F-06`). Service paths are absolute —
`/api/auth/...` and `/api/v1/events/...`.

| Method | Path                                                          | Purpose                                                  | Auth               |
| ------ | ------------------------------------------------------------- | -------------------------------------------------------- | ------------------ |
| POST   | `/api/auth/login`                                             | Login                                                    | none               |
| GET    | `/api/users/me`                                               | Current user (session rehydrate)                         | Bearer             |
| GET    | `/api/v1/events/my-managed`                                   | Events I manage (paginated; `_meta` carries role/counts) | Bearer             |
| GET    | `/api/v1/events/by-id/:eventId`                               | Single event                                             | Bearer             |
| GET    | `/api/v1/events/:eventId/ticket-types`                        | Ticket types (read-only)                                 | Bearer             |
| GET    | `/api/v1/events/:eventId/registrations`                       | Registration list (pagination + `status`)                | Bearer             |
| GET    | `/api/v1/events/:eventId/registrations/by-code/:code`         | Lookup by code (3s timeout)                              | Bearer             |
| POST   | `/api/v1/events/:eventId/registrations/checkin`               | Check in                                                 | Bearer (OPERATOR+) |
| POST   | `/api/v1/events/:eventId/registrations/checkin/override`      | Supervisor override                                      | Bearer             |
| GET    | `/api/v1/events/:eventId/nfc/lookup`                          | Badge lookup (uid or qr)                                 | Bearer             |
| POST   | `/api/v1/events/:eventId/nfc/bind`                            | Bind badge ↔ registration                                | Bearer (OPERATOR+) |
| POST   | `/api/v1/events/:eventId/nfc/exchange`                        | Record a card exchange                                   | Bearer             |
| GET    | `/api/v1/events/:eventId/nfc/badges`                          | Badge inventory (paginated)                              | Bearer (write)     |
| GET    | `/api/v1/events/:eventId/wallet/:registrationId/transactions` | Token ledger                                             | Bearer             |

Reproduce: `grep -rhoE "[\"'\`]/api/[^\"'\`]_" src | sed 's/^[^/]_//' | sort -u` → **14** paths.

> The backend exposes **121** endpoints under `/api/v1/events`. This app consumes **14** (≈11.6%).
> That narrow slice is intentional. The backend has **zero** `@openapi` annotations for the event
> vertical, so the contract is **not machine-checked** — treat this table as a hand-maintained cache
> and verify against the service files.

## Environment Variables

| Variable              | Source                                         | Behaviour when missing                                                                                                                     |
| --------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `EXPO_PUBLIC_API_URL` | `.env.local` (dev) / `eas.json` `env` (builds) | **`F-07`: fail closed.** Non-dev build → `API_CONFIG.ok === false`; startup error screen; every request rejected with `APP_CONFIG_INVALID` |
| `EXPO_PUBLIC_WEB_URL` | same                                           | defaults to `https://linkcard.xyz` (web origin, used for card/profile URLs)                                                                |

- All three EAS profiles set both variables. The guard only fires when someone removes one — which is
  exactly the case worth failing on.
- **`EXPO_PUBLIC_*` is build-time inlined.** Changing it requires restarting Metro; hot reload will not
  pick it up.
- `EXPO_PUBLIC_*` is **not** a secret store — it is inlined into the bundle and shipped to anyone.
- `.env.example` is committed; `.env.local` is gitignored.

## Naming Conventions

| Layer                     | Convention                           | Examples                                            |
| ------------------------- | ------------------------------------ | --------------------------------------------------- |
| Services / stores / utils | camelCase + layer suffix             | `auth.service.ts`, `event.store.ts`, `api-error.ts` |
| Components                | PascalCase                           | `Button.tsx`, `AppConfigErrorScreen.tsx`            |
| Routes                    | camelCase, kebab-case filenames      | `home.tsx`, `check-in.tsx`, `nfc-bind.tsx`          |
| Dynamic segments          | `[param]` brackets + camelCase       | `[eventId]`, `[registrationId]`                     |
| Types                     | camelCase + `.types.ts`              | `api.types.ts`                                      |
| Constants                 | camelCase + `.ts`                    | `config.ts`, `copy.zh-TW.ts`                        |
| Imports                   | `@/*` → `src/*`, enforced sort order | prettier `sort-imports` plugin                      |

**All user-visible strings live in `src/constants/copy.zh-TW.ts`.** Hard-coded Chinese in a screen is a
defect, not a shortcut.
