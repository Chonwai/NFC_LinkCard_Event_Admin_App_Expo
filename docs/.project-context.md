## Tech Stack

- **Runtime**: Expo SDK `~57.0.13` / React Native `0.86.2` / React `19.2.3` / TypeScript `~6.0.3`
- **Router**: expo-router `~57.0.13` — file-based routing under `src/app/`，`experiments.typedRoutes: true`
- **State**: zustand `^5.0.15` — 2 stores（auth / event）
- **HTTP**: axios `^1.19.0` — `src/services/api.ts` 單例，JWT bearer token interceptor（與 Promoter 同架構）
- **Native modules**: react-native-nfc-manager（NFC 入場憑證綁定）、expo-camera（QR scan check-in）、expo-secure-store（token 持久化）、expo-linking（deep link）
- **UI 輔助**: react-native-safe-area-context、react-native-screens、react-native-svg + react-native-qrcode-svg、react-native-web
- **Styling**: React Native StyleSheet + 三層 design token（`src/constants/theme.ts` — **100% 複製自 Promoter App**，primitive → semantic → component）
- **Lint/Format**: eslint 9 + eslint-config-expo、prettier + @trivago/prettier-plugin-sort-imports、husky 9 + lint-staged 15
- **Testing**: 無 test framework
- **Build**: EAS Build（eas.json：development / preview / production profiles）
- **Type checking**: `package.json` 有 `typecheck: tsc --noEmit` script（**Promoter 無**）
- **Platform**: iOS `supportsTablet: true`；Android permissions = CAMERA + NFC（**無 RECORD_AUDIO**，Promoter 有）

## API Endpoint Inventory

> Backend 契約（來源：`DEV_LOG.md` + service 內文）。Base URL = `API_BASE_URL`（production 預設 `https://linkcard.xyz/api`）。

| Method | Path | 用途 | Auth |
| --- | --- | --- | --- |
| POST | `/v1/auth/login` | 管理員登入 | 無 |
| GET | `/v1/events/my-managed` | 我管理的活動列表（分頁） | Bearer JWT |
| GET | `/v1/events/:eventId/registrations/by-code/:code` | 依報名代碼查詢報名 | Bearer JWT |
| POST | `/v1/events/:eventId/registrations/checkin` | QR 掃描報到 | Bearer JWT |
| GET | `/v1/events/:eventId/badges` | Badge 列表（NFC 綁定用） | Bearer JWT |
| POST | `/v1/events/:eventId/badges/:badgeId/nfc-bind` | NFC 入場憑證綁定 | Bearer JWT |

> 確切 path prefix 以 service 內文為準（DEV_LOG 記載 login / my-managed / by-code / checkin 四支；badges 兩支由 nfc.service 提供）。
